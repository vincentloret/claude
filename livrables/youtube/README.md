# Livrables — YouTube

> Briefs vidéo, scripts, storyboards et éléments préparatoires pour du contenu YouTube.

---

## Ce qui va ici

- Scripts de vidéo (voix off, dialogue caméra)
- Briefs vidéo (angle, cible, promesse, plan)
- Storyboards texte ou plans de tournage
- Titres et descriptions optimisés
- Chapitrages et timecodes
- Idées d'accroches (thumbnails texte, hooks)
- Miniatures de vignettes (concepts et wireframes)

## Ce qui ne va PAS ici

- Vidéos montées ou rushes bruts (trop lourds pour git, à stocker ailleurs)
- Site web du canal YouTube → `livrables/sites-web/`
- Automatisations de publication → `livrables/applications/`

---

## Convention de nommage

Format standard `AAAA-MM-JJ_nom-du-projet/` (voir `livrables/README.md`).

**Exemples pour ce dossier :**
- `2026-07-25_video-01-repositionnement-pro/`
- `2026-08-15_serie-ux-et-ia/`

---

## Structure recommandée par projet

```
AAAA-MM-JJ_nom-du-projet/
├── README.md          ← brief, cible, angle, statut de production
├── brief.md           ← promesse, plan, ton, cible détaillée
├── script.md          ← script complet de la vidéo
├── titre-description.md ← titre YouTube + description + hashtags
└── vignette/          ← concepts de miniature
```
